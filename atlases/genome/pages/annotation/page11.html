What this page shows
spec · phase C
Three views over the recombination map of the F₁ hybrid, pared down from the aye-aye CO paper's Fig.1 (Versoza et al. GBE 2024). We keep the panels that read well at a glance and drop the ones the F₁ data can't support: no parental-age regression (single generation) and no AlphaFold panel (decorative).
The PRDM9 motif logo is facultative: when the prdm9_motif layer is absent or its pwm field is null, the renderer hides the logo card entirely (the spec DOM keeps it as a placeholder).

View 1 — sex-specific CO ideogram
primary view
One vertical chromosome rod per LG; CO events as dots beside the rod, jittered along the rod axis at their physical position. females on the left side, males on the right. Optional overlay (toggle): NCO as small green ticks, gene conversion as small yellow ticks (NCO/GC tracts often co-locate with CO hotspots — green + yellow read as complements next to red/blue).

View 2 — CO rate vs. relative telomere distance
primary view
x-axis: relative distance from telomere (0 = telomere, 1 = centre of chromosome arm). y-axis: # COs per individual per bin. One smoothed curve per sex (red / blue) with a 95% CI band. Optional NCO (green) and GC (yellow) curves overlay on the same axes — toggle from the legend.

View 3 — PRDM9 binding motif optional
hidden when no pwm

Import schema — crossover_track.json
contract
One JSON per candidate analysis. events drives View 1; per-bin sex curves drive View 2; prdm9_motif is facultative; nco_gc_track is facultative. All optional fields may be omitted entirely — the corresponding panel/overlay self-hides. 
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "crossover_track",
  "type": "object",
  "required": ["candidate_id", "chroms", "events"],
  "properties": {
    "candidate_id":  { "type": "string" },
    "cohort":        { "type": "string" },
    "individuals":   { "type": "integer", "minimum": 1 },

    "chroms": {
      "type": "array",
      "items": {
        "type": "object",
        "required": ["id", "length_bp"],
        "properties": {
          "id":          { "type": "string" },
          "length_bp":   { "type": "integer", "minimum": 1 },
          "telomere_L":  { "type": "integer" },
          "telomere_R":  { "type": "integer" }
        }
      }
    },

    "events": {
      "type": "array",
      "description": "One entry per detected CO.",
      "items": {
        "type": "object",
        "required": ["chrom", "pos_bp", "sex"],
        "properties": {
          "chrom":  { "type": "string" },
          "pos_bp": { "type": "integer", "minimum": 0 },
          "sex":    { "enum": ["F", "M"] },
          "indiv":  { "type": "string" }
        }
      }
    },

    "telomere_curve": {
      "description": "Pre-binned curve for View 2. If omitted, renderer bins `events` on the fly.",
      "type": "object",
      "properties": {
        "bins":    { "type": "array", "items": { "type": "number", "minimum": 0, "maximum": 1 } },
        "female":  { "$ref": "#/$defs/curve" },
        "male":    { "$ref": "#/$defs/curve" },
        "nco":     { "$ref": "#/$defs/curve" },
        "gc":      { "$ref": "#/$defs/curve" }
      }
    },
    "curve_params": {
      "type": "object",
      "properties": {
        "smoother":      { "enum": ["loess", "spline", "none"] },
        "span":          { "type": "number", "minimum": 0, "maximum": 1 },
        "ci_bootstrap":  { "type": "integer", "minimum": 0 }
      }
    },

    "prdm9_motif": {
      "description": "Facultative. When omitted or `pwm` is null, View 3 hides itself.",
      "type": ["object", "null"],
      "properties": {
        "pwm": {
          "type": ["array", "null"],
          "description": "N×4 position-weight matrix, ACGT.",
          "items": {
            "type": "array",
            "minItems": 4, "maxItems": 4,
            "items": { "type": "number", "minimum": 0, "maximum": 1 }
          }
        },
        "tool":   { "enum": ["MEME", "STREME", "HOMER", "manual"] },
        "evalue": { "type": "number" },
        "n_hotspots": { "type": "integer", "minimum": 0 }
      }
    },

    "nco_gc_track": {
      "description": "Facultative NCO / gene-conversion tracts. Drives the green/yellow overlays.",
      "type": ["array", "null"],
      "items": {
        "type": "object",
        "required": ["chrom", "start_bp", "end_bp", "kind"],
        "properties": {
          "chrom":     { "type": "string" },
          "start_bp":  { "type": "integer", "minimum": 0 },
          "end_bp":    { "type": "integer", "minimum": 0 },
          "kind":      { "enum": ["nco", "gc"] },
          "indiv":     { "type": "string" }
        }
      }
    }
  },

  "$defs": {
    "curve": {
      "type": "object",
      "properties": {
        "y":     { "type": "array", "items": { "type": "number" } },
        "ci_lo": { "type": "array", "items": { "type": "number" } },
        "ci_hi": { "type": "array", "items": { "type": "number" } }
      }
    }
  }
}
One file = one candidate (candidate_id namespaces it). Drop multiple files into data/annotation/crossovers/ to flip between cohorts without re-binding the layer.
