▰ Genes — track, density, cargo
Stage: annotation · spec / phase B–C · driven by gene_track
What this page shows
spec · phase B (track) → phase C (cargo)
Three views over the gene annotation: (1) genome-wide density — per-chromosome gene-count histogram; (2) per-chromosome track — gene models on a length-scaled axis for one chrom at a time (driven by shared.activeChrom); (3) gene cargo per inversion — for every promoted candidate in the Inversion Atlas, list the genes that fall inside the inversion span, sorted by SnpEff impact when variant_annotations is loaded.
The cargo view is the bridge between the assembly paper and the Inversion Atlas's manuscript — it answers "what does this inversion break?" without leaving the tool.

Three views (overview)
phase plan
View 1 — genome-wide density
Bar chart, one bar per chromosome, height = gene count. Sort by length or by count. Highlights cross-haplotype asymmetries (Gar vs Mac).
View 2 — per-chrom gene track
Gene models drawn as boxes (exons) + lines (introns) along a length-scaled axis. Color by strand. Hover to surface gene name + functional annotation. Width matches the Inversion Atlas scrubber so two windows can be stacked.
View 3 — gene cargo per inversion
Table: candidate id · chrom · span · gene count · gene list (truncated) · max impact (HIGH / MODERATE / LOW / MODIFIER). Reads cross-atlas from shared.candidates.
View 1 — Gene density per chromosome
sample data
One bar per chromosome, height ∝ gene count. Toggle the haplotype filter or sort direction; click any bar to scroll View 2 to that chromosome.
hap sort
View 2 — Per-chromosome gene track
sample data · pick a chrom
Gene models on a length-scaled axis for one chromosome. Boxes = exons (or single-exon gene span when exon detail is absent); colour encodes strand (+ forward / − reverse). Hover any gene for its name and biotype.
chrom strand
View 3 — Gene cargo per inversion candidate
sample candidates
One row per promoted candidate read from shared.candidates (Inversion-Atlas cross-atlas slot). Cargo = genes whose span overlaps the candidate's [start_bp, end_bp] interval on the same chromosome. Impact column populates from variant_annotations when it lands (phase E); meanwhile the column reports "—".
