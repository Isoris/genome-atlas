▰ Conserved elements — UCEs / phastCons
Stage: annotation · spec / phase C–D · driven by conserved_elements
What this page shows
spec · phase C–D
Ultra-conserved elements (UCEs) and phastCons-derived conserved regions rendered as a regulatory-disruption sub-track. Scores how much conserved sequence each inversion candidate overlaps — a candidate that disrupts a UCE has a different functional weight than one that doesn't, independent of gene content.
Complements page5 (gene cargo) by counting regulatory hits, not just coding hits.

Views (mockup)
phase plan
View 1 — per-chrom element strip
Tick strip along the active chromosome; each tick = one conserved element. Width matches the Inversion Atlas scrubber.
View 2 — per-candidate UCE overlap
Table: candidate id · UCE count inside span · summed conserved-bp · max phastCons score in span. Bubble up to the Inversion Atlas catalogue as a "regulatory disruption" badge.
View 3 — phastCons score profile
Continuous score track (phastCons posterior probability) along the active chromosome. Highlights conserved peaks not annotated as UCEs.
