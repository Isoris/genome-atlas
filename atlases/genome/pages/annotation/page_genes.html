What this page shows
spec · phase B (track) → phase C (cargo)
Three views over the gene annotation: (1) genome-wide density — per-chromosome gene-count histogram; (2) per-chromosome track — gene models on a length-scaled axis for one chrom at a time (driven by shared.activeChrom); (3) gene cargo per inversion — for every promoted candidate in the Inversion Atlas, list the genes that fall inside the inversion span, sorted by SnpEff impact when variant_annotations is loaded.
The cargo view is the bridge between the assembly paper and the Inversion Atlas's manuscript — it answers "what does this inversion break?" without leaving the tool.

Three views (mockup)
phase plan
View 1 — genome-wide density
Bar chart, one bar per chromosome, height = gene count. Sort by length or by count. Highlights cross-haplotype asymmetries (Gar vs Mac).
View 2 — per-chrom gene track
Gene models drawn as boxes (exons) + lines (introns) along a length-scaled axis. Color by strand. Hover to surface gene name + functional annotation. Width matches the Inversion Atlas scrubber so two windows can be stacked.
View 3 — gene cargo per inversion
Table: candidate id · chrom · span · gene count · gene list (truncated) · max impact (HIGH / MODERATE / LOW / MODIFIER). Reads cross-atlas from shared.candidateList.
