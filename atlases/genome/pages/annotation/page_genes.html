▰ Genes — track, density, cargo
Stage: annotation · spec / phase B–C · driven by gene_track
What this page shows
spec · phase B (track) → phase C (cargo)
Three views over the gene annotation: (1) genome-wide density — per-chromosome gene-count histogram; (2) per-chromosome track — gene models on a length-scaled axis for one chrom at a time (driven by shared.activeChrom); (3) gene cargo per inversion — for every promoted candidate in the Inversion Atlas, list the genes that fall inside the inversion span, sorted by SnpEff impact when variant_annotations is loaded.
The cargo view is the bridge between the assembly paper and the Inversion Atlas's manuscript — it answers "what does this inversion break?" without leaving the tool.

Gene models drawn as boxes (exons) + lines (introns) along a length- scaled axis. Colour by strand (coral = forward, neutral = reverse). Hover for gene name + functional annotation. Width matches the Inversion Atlas scrubber so two windows can be stacked. Driven by activeChrom.

Import schema — gene_track.gff
GFF3 · standard fields
The gene track is a standard GFF3 file (no atlas-specific JSON). The renderer materializes it into per-chrom in-memory arrays at mount; the dispatcher's import_table runner can also ingest it into a staging_genome_table_v0 envelope for forensic queries. 
# gene_track.gff (GFF3)
# Standard 9-column format. The atlas reads:
#   col 1: seqid       (chrom; matches assembly_stats.per_chrom[*].chrom)
#   col 3: type        ('gene' | 'mRNA' | 'exon' | 'CDS' | 'five_prime_UTR' | ...)
#   col 4: start_bp    (1-based, GFF3 convention)
#   col 5: end_bp      (inclusive)
#   col 7: strand      ('+' | '-' | '.')
#   col 9: attributes  (ID=...; Name=...; product=...; gene_biotype=...)
#
# Example rows (the renderer paginates by chrom):
