▰ Repeats / TE landscape
Stage: annotation · spec / phase B · driven by repeat_track
What this page shows
spec · phase B
Genome-wide TE / repeat composition for both parental haplotypes (Gar: 28 chroms, Mac: 27 chroms). Three views: per-class composition (LTR / LINE / SINE / DNA / simple / unclassified), per-chromosome density (heatmap, chrom × class), and breakpoint enrichment — for every promoted inversion candidate, test whether the flank repeat density exceeds the per-chromosome mean (Spalax-style all_TE flag).
The breakpoint enrichment view ties this annotation page directly to the inversion-evolution mechanism the manuscript argues for.

Three views (mockup)
phase plan
View 1 — per-class composition
Stacked bar per haplotype: LTR · LINE · SINE · DNA · simple · unclassified. Shows whether Gar and Mac differ in TE class balance — relevant for the inversion-mechanism story.
View 2 — per-chrom density heatmap
Rows = chromosomes (Gar then Mac), columns = TE classes, cells = density. Sort rows by total repeat fraction. Hover for raw bp counts.
View 3 — breakpoint enrichment
For each Inversion-Atlas candidate, run the focal-vs-background widget (Spalax method) on the inversion flank (~2 Mb). Surface a ● badge when flank density ≥1.5× chrom mean; bubble up the badge to the catalogue table on the Inversion Atlas.
View 4 — TE hierarchy Sankey
Interactive flow diagram: Class → Superfamily → Family. Each Class is unfoldable — click a node to collapse / expand its descendants, or toggle the global depth from the toolbar. Renders directly below from te_hierarchy; falls back to a sample dataset while the layer is not loaded.
View 4 — TE hierarchy alluvial (per parental haplotype)
sample data
Alluvial flow over the full repeat hierarchy: Non-repetitive · Repetitive → Interspersed_TEs · Tandem_repeats · Other_repeats → Class → Order → Family. One panel per parental haplotype — (a) C. gariepinus and (b) C. macrocephalus. Bar height ∝ % of total genome; labels carry the percentage inline. Click any non-leaf node to fold / unfold its descendants, or reset the visible depth from the toolbar.

Figure X. Transposable-element landscapes of parental haplotypes in the F₁ hybrid catfish genome. Alluvial diagrams summarising genome-wide repeat composition and hierarchical classification of transposable elements in the parental haplotypes: (a) Clarias gariepinus and (b) C. macrocephalus.

Data contract: te_hierarchy.json — { haplotypes: [{ id, name, label, nodes: […] }] }, where each node = { id, name, pct, palette?, children? } and pct is percent of the whole genome (children sum ≤ parent.pct). The renderer auto-derives column index from depth in the tree and is depth-agnostic. Until the layer lands it falls back to a sample two-haplotype dataset baked into page6.js.
