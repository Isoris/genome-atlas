What this page shows
spec · phase B
Genome-wide TE / repeat composition for both parental haplotypes (Gar: 28 chroms, Mac: 27 chroms). Three views: per-class composition (LTR / LINE / SINE / DNA / simple / unclassified), per-chromosome density (heatmap, chrom × class), and breakpoint enrichment — for every promoted inversion candidate, test whether the flank repeat density exceeds the per-chromosome mean (Spalax-style all_TE flag).
The breakpoint enrichment view ties this annotation page directly to the inversion-evolution mechanism the manuscript argues for.

Data contract: te_hierarchy.json — { haplotypes: [{ id, name, label, nodes: […] }] }, where each node = { id, name, pct, palette?, children? } and pct is percent of the whole genome (children sum ≤ parent.pct). The renderer auto-derives column index from depth in the tree and is depth-agnostic. Until the layer lands it falls back to a sample two-haplotype dataset baked into page6.js.

The all-TE adapter is a Python generator under the hood. The raw GFF is millions of features for a catfish-sized genome — the extractor processes line-by-line and emits a small JSON envelope of aggregated counts only. Per-feature rows are NOT carried in the payload (per the schema). Params min_length_bp + keep_unknown let the caller pre-filter without re-running EDTA. See fixtures/edta/ for example inputs + smoke-test commands.
Import schema — te_hierarchy_v0
JSON Schema · draft-07
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "$id": "te_hierarchy_v0.schema.json",
  "title": "EDTA all-TE aggregated counts",
  "description": "Streamed-aggregate payload for *.EDTA.TEanno.gff3. Per-feature rows are NOT in this payload by design — the raw GFF is millions of features. Counts + bp sums by (Class, Superfamily, Family) and (chrom × Class).",
  "type": "object",
  "required": ["source", "n_features", "total_bp", "by_class", "by_superfamily", "schema_version"],
  "properties": {
    "source":         { "type": "string" },
    "n_features":     { "type": "integer", "minimum": 0 },
    "total_bp":       { "type": "integer", "minimum": 0 },
    "schema_version": { "const": "te_hierarchy_v0" },
    "params":         { "type": "object" },

    "by_class": {
      "type": "object",
      "description": "Class → {n, bp}. Classes: LTR | LINE | SINE | DNA | Helitron | rRNA | Unknown.",
      "additionalProperties": { "$ref": "#/$defs/count_bp" }
    },
    "by_superfamily": {
      "type": "object",
      "description": "Superfamily → {n, bp}. EDTA's Classification[0].",
      "additionalProperties": { "$ref": "#/$defs/count_bp" }
    },
    "by_class_super": {
      "type": "object",
      "additionalProperties": {
        "type": "object",
        "additionalProperties": { "$ref": "#/$defs/count_bp" }
      }
    },
    "by_super_family": {
      "type": "object",
      "additionalProperties": {
        "type": "object",
        "additionalProperties": { "$ref": "#/$defs/count_bp" }

    },
    "per_chrom_class": {
      "type": "object",
