What this page shows
spec · phase E (final piece)
SnpEff / VEP impact category summaries per inversion candidate. Answers "what does this inversion break?" by counting and listing the variants of each severity (HIGH / MODERATE / LOW / MODIFIER) that fall inside the inversion span. Supports the manuscript's deleterious-burden argument.
Final piece of the Genome Atlas — depends on MODULE_CONSERVATION deliverables (VESM / SIFT4G / SnpEff / GERP++) landing on the cluster. Don't migrate until phase D synteny is done.

Views (mockup)
phase plan
View 1 — per-candidate tally
Table: candidate id · HIGH count · MODERATE count · LOW count · MODIFIER count · top-3 HIGH-impact genes. One row per promoted candidate from the Inversion Atlas.
View 2 — impact bar per candidate
Compact horizontal bar (HIGH = red, MODERATE = amber, LOW = neutral, MODIFIER = dim) showing the relative composition. Easy comparison across candidates.
View 3 — HIGH-impact variant list
Per-variant detail for every row where impact = HIGH. Columns: chrom · pos · gene · effect. Sortable, filterable, exportable as TSV. (When GERP++ / VEP consequence columns land in the upstream payload they'll surface automatically — the renderer reads whatever the extractor emits.)
