What this page shows
spec · phase B (primary deliverable)
One row per chromosome, length-scaled across the page width. Each row stacks four density tracks: gene density, repeat density, conserved-element density, and the active cohort's L2 envelopes + promoted candidates (read cross-atlas from the Inversion Atlas's candidates_registry). Hover for per-window values; click a row to drill into the per-chromosome detail view (future page).
This is the Genome Atlas's main "map of the map" — the page that makes the assembly tangible. Mirror the Inversion Atlas's scrubber width so users can mentally align the two side-by-side.

Chromosome strip
sample data
hap
gene density repeat density conserved (ticks) cohort envelope / candidate centromere
One row per chromosome, length-scaled. Bar widths are chrom.length_bp / max(length_bp) of the available track region. Centromere band overlays from centromere_telomere; cohort envelope + candidate markers from shared.candidates (cross-atlas, Inversion Atlas). Hover any track for the bin's value; click a row to dispatch a ga-strip-chrom-click event the shell can route to a per-chromosome detail view.
Sub-track stacking order
design note
1. base bar
Length-scaled chromosome backbone. Centromere band overlay from centromere_telomere.
2. gene density
Heatmap stripe (panel-3 → accent gradient). 100 kbp bins.
3. repeat density
Heatmap stripe (panel-3 → bad gradient). Same binning.
4. conserved density
Dot strip — UCE positions as ticks.
5. cohort overlay
L2 envelope rectangles + candidate markers from the Inversion Atlas. Hidden when activeChrom is null.
