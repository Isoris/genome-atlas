▰ Assembly methods — HiFi + Hi-C + ONT pipeline
Stage: assembly · spec / phase B · documentation page · no layer dependencies
What this page shows
spec · phase B
The haplotype-resolved assembly pipeline that produced the F₁ hybrid reference: PacBio HiFi for base accuracy, Hi-C for long-range scaffolding + haplotype phasing, Oxford Nanopore for gap closure and structural-variant signal. Each stage links to the manuscript methods section + the relevant cluster-side workflow.
Pure documentation — no live data, no renderer. Stays useful as long as the assembly paper is in review.
Pipeline stages
narrative
stage 1
PacBio HiFi reads → primary contigs (hifiasm). Phased with Hi-C reads to produce two haplotype-resolved contig sets.
stage 2
Hi-C scaffolding (YaHS / SALSA2). Contig sets join into chromosome-scale scaffolds; haplotype 1 = Gar parent, haplotype 2 = Mac parent.
stage 3
ONT polishing + gap closure (Medaka / TGS-GapCloser). Reduces N-runs, improves homopolymer accuracy, fills inter-contig gaps.
stage 4
Curation pass (manual + Pretext / Hi-C contact-map review). Misjoins resolved, orientation flips fixed, final FAI + AGP emitted.
stage 5
QC (BUSCO + asmstats + tidk + merqury). Outputs back the assembly_stats + centromere_telomere layers used by page_assembly_stats.
Data inputs
cohort: F₁ hybrid only
PacBio HiFi
~30× coverage per parent. Source of base-accuracy phased contigs.
Hi-C (Arima)
~50× coverage. Drives both scaffolding and trio-free haplotype phasing.
Oxford Nanopore
~20× coverage. Gap closure, structural-variant signal for downstream Inversion Atlas validation.
Optical map (Bionano, optional)
Curation cross-check for chromosome-scale ordering.
