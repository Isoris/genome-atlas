▰ Assembly methods — HiFi + Hi-C + ONT pipeline
Stage: assembly · spec / phase B · documentation page · no layer dependencies
What this page shows
spec · phase B
The haplotype-resolved assembly pipeline that produced the F₁ hybrid reference: PacBio HiFi for base accuracy, Hi-C for long-range scaffolding + haplotype phasing, Oxford Nanopore for gap closure and structural-variant signal. Each stage links to the manuscript methods section + the relevant cluster-side workflow.
Pure documentation — no live data, no renderer. Stays useful as long as the assembly paper is in review.

Pipeline stages — detail
narrative
stage 1
PacBio HiFi reads → primary contigs (hifiasm 0.19.7 with --hic1 / --hic2). Phased with the Hi-C reads in-line to produce two haplotype-resolved contig sets. Trio-binning is not used — the F₁'s parents weren't sequenced separately at the time of assembly.
stage 2
Hi-C scaffolding (YaHS 1.2a) per haplotype. Contig sets join into chromosome-scale scaffolds; haplotype 1 → 28 Cgar LGs, haplotype 2 → 27 Cmac LGs. SALSA2 was tested in parallel; YaHS won on N50 + manual-curation effort.
stage 3
ONT polishing + gap closure. Medaka (v1.11.3) on the Hi-C-scaffolded assembly with ONT reads (~20× R10.4 coverage); TGS-GapCloser (v1.2.1) closes inter-contig N-runs; a second DeepVariant pass catches residual indels in low-complexity regions.
stage 4
Manual curation — Pretext-Map / Hi-C contact-map review. ~2 person-days. Misjoins resolved by AGP edits; orientation flips fixed. Final per-haplotype FAI + AGP emitted; the AGP is the structural ground truth from this point on.
stage 5
QC (BUSCO + asmstats + Merqury + tidk + EDTA). Roll-up into assembly_stats.json — the consolidated file page_assembly_stats reads. See fixtures/assembly_qc/ for an end-to-end example of the QC bundle this stage produces.

Data inputs
cohort: F₁ hybrid only
PacBio HiFi
~30× coverage per parent. Source of base-accuracy phased contigs.
Hi-C (Arima)
~50× coverage. Drives both scaffolding and trio-free haplotype phasing.
Oxford Nanopore
~20× coverage. Gap closure, structural-variant signal for downstream Inversion Atlas validation.
Optical map (Bionano, optional)
Curation cross-check for chromosome-scale ordering.
