▰ Ancestral karyotype — teleost / siluriform reconstruction
Stage: comparative · spec / phase D · supp note candidate
What this page shows
spec · phase D
Reconstructed ancestral karyotype for the catfish (Siluriformes) lineage, derived from the same Cactus multi-genome alignment that feeds page9. Shows which Cgar chromosomes descend from which ancestral elements, where fissions / fusions / inversions occurred on each branch of the catfish phylogeny.
Most likely promoted to a Supplementary Note for the assembly paper (not a main figure). The atlas page is the interactive companion that lets reviewers drill into individual ancestral elements.

View 1 — ancestral karyotype panel
N ancestral chromosomes drawn as bars at the top of the figure, color-coded by element identity (A1, A2, …). Below: each extant species' chromosomes coloured by which ancestral element they descend from.
View 2 — phylogeny with event annotations
Siluriformes phylogeny (Cgar, Cmac, I. punctatus, plus outgroups). Each branch annotated with the chromosomal events inferred along it (fission count, fusion count, inversion count, segmental duplications).
View 3 — per-element descent
Click an ancestral element to highlight every extant chromosome (across all species) that carries part of it. Useful for the "what happened to ancestral element A7?" narrative.
View 1 — reconstructed ancestral karyotype (painted)
Siluriformes ancestor · 13 ALGs
Inferred ancestral linkage groups (ALG1 … ALG13) drawn as painted capsules — flat fills with alpha, one hue per ALG. The painting style follows WGDI's karyotype module (Sun et al. Molecular Plant 2022, BSD-licensed; see cross-refs). The ALG hues here are the canonical palette reused on Views 2 + 3 and on every extant strip below.
ALG count and identity are the inference output; real renderer reads synteny_blocks.ancestral.lens + the ALG label map and lays out chromosomes proportionally to inferred ancestral chrom length.
View 2 — extant chromosomes painted by ALG descent
Cgar (28 chroms) · WGDI painting style
Each modern Cgar chromosome is a painted capsule: ALG-coloured rectangles tile the bar in the order they appear along the chromosome. A chrom that derives from a single ALG reads as one colour; a fusion product reads as two side-by-side colours; a chrom that has been broken by a fission may appear shorter and single-coloured but with a fragmented sibling. Click an ALG in View 1 above to highlight every cell that carries it (the highlight is wired in View 3's section).
Mockup: LG02 + LG05 are fusion products (two ALGs tiled side-by-side); LG11 + LG12 are sibling fragments of a fissioned ALG13 (both painted in the same ALG13 hue). Real renderer reads synteny_blocks.descent and tiles by inferred ancestral block span.
View 3 — Siluriformes phylogeny with event annotations
events per branch
A simple cladogram for Cgar + Cmac + I. punctatus + P. hypophthalmus + an outgroup, with per-branch event tallies inferred from the multi-species Cactus alignment. Each tip's chrom count is shown; each internal node carries the chromosomal event budget (fissions f, fusions F, inversions i) inferred along that branch.
Legend: f = fission count, F = fusion count, i = inversion count. Real renderer reads the Siluriformes species tree from data/comparative/phylogeny.nwk and per-branch event tallies from synteny_blocks.events (phase D).
