▰ Ancestral karyotype — teleost / siluriform reconstruction
Stage: comparative · spec / phase D · supp note candidate
What this page shows
spec · phase D
Reconstructed ancestral karyotype for the catfish (Siluriformes) lineage, derived from the same Cactus multi-genome alignment that feeds page9. Shows which Cgar chromosomes descend from which ancestral elements, where fissions / fusions / inversions occurred on each branch of the catfish phylogeny.
Most likely promoted to a Supplementary Note for the assembly paper (not a main figure). The atlas page is the interactive companion that lets reviewers drill into individual ancestral elements.

Views (mockup)
phase plan
View 1 — ancestral karyotype panel
N ancestral chromosomes drawn as bars at the top of the figure, color-coded by element identity (A1, A2, …). Below: each extant species' chromosomes coloured by which ancestral element they descend from.
View 2 — phylogeny with event annotations
Siluriformes phylogeny (Cgar, Cmac, I. punctatus, plus outgroups). Each branch annotated with the chromosomal events inferred along it (fission count, fusion count, inversion count, segmental duplications).
View 3 — per-element descent
Click an ancestral element to highlight every extant chromosome (across all species) that carries part of it. Useful for the "what happened to ancestral element A7?" narrative.
