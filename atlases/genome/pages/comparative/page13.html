▰ Orthologues — focal vs. non-focal genomes
Stage: comparative · spec / phase D · driven by ortholog_tables · optional deep-dive: ortholog_pairs · shares focal selection with page9
What this page shows
spec · phase D
Three tables comparing one focal genome against every other non-focal genome in the comparison set: (1) a summary table with one row per non-focal — counts of 1:1, 1:n, m:1, m:n orthology and orphans; (2) a per-chrom breakdown of the focal genome showing how its chromosomes are accounted for in each non-focal; (3) a gene-level explorer — one row per focal gene with its ortholog in each non-focal (or "—" for an orphan), filterable by gene id.
The focal genome is selectable below. The selector mirrors page9's "genome A" dropdown — flipping it here also flips the Oxford grid's row axis if both pages are mounted.

View 1 — focal × non-focal summary
primary table
One row per non-focal genome. Counts are gene counts on the focal side except where noted. 1:1 = single ortholog both ways; 1:n / m:1 = duplications; m:n = complex; orphans = focal genes with no ortholog in that non-focal.

% mapped = (1:1 + 1:n + m:1 + m:n) / focal gene count. Hover any row for genome metadata (assembly accession, gene-count source); click to deep-dive into the gene-level explorer scoped to that non-focal (View 3).

View 3 — gene-level explorer
filterable · paginated
One row per focal gene. Type a gene id (or prefix) to filter; the renderer paginates 50 rows at a time. Cells hold the ortholog id for the corresponding non-focal genome — or "—" for an orphan; a superscript copy count appears when there is more than one ortholog (1:n).

Import schemas
contract
ortholog_tables.json is one file per focal genome and carries everything needed for Views 1 + 2. ortholog_pairs.json is one file per (focal, non-focal) pair, loaded lazily only when View 3 reveals a column.
