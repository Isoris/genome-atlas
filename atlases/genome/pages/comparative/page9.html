Stage: comparative · spec / phase D · driven by synteny_blocks + macrosynteny_orthologs
What this page shows
spec · phase D
Cross-species collinearity for the Gar haplotype against related Siluriformes (C. macrocephalus, I. punctatus, plus 7-9 more catfish genomes via catfish-synteny-toolkit's wfmash 1-to-1 alignments). Four views: pairwise ribbon, multi-species ribbon stack, a MacrosyntR-style Oxford macro-synteny grid (orthologs as dots, chromosomes reordered for best diagonal), and a per-chrom dotplot.
Where the Inversion Atlas's page16 surfaces cross-species breakpoint coincidences with cohort candidates, this page is the genome-wide context the breakpoints live in.

Views (mockup)
phase plan
View 1 — pairwise ribbon
Two horizontal strips (e.g. Cgar above, Cmac below); polygons connect homologous blocks. Inversions = anti-parallel polygons. Translocations = chrom-jumping polygons. Toggle which species is shown below.
View 2 — multi-species ribbon stack
Cgar at the top; stacked below it, one strip per related Siluriformes genome. Side-by-side comparison of conserved vs lineage-specific rearrangements.
View 3 — MacrosyntR Oxford grid
Whole-genome Oxford dotplot — x-axis = chroms of species A, y-axis = chroms of species B, length-scaled and reordered so the strongest pairwise matches sit on the diagonal. Each dot is one ortholog gene pair; colour encodes the y-chromosome. Direct port of macrosyntR::plot_oxford_grid.
View 4 — per-chrom dotplot
Click any chromosome in the ribbon to open a full dotplot (Cgar chrom × homolog chrom). Hover for block coordinates and identity.
View 3 — MacrosyntR Oxford macro-synteny grid
sample data
Whole-genome Oxford grid. Rows + columns are length-scaled chromosomes, reordered greedily so the strongest pairwise hits straighten to a diagonal (MacrosyntR's reorder=TRUE default). Each dot is one orthologous gene pair; colour encodes the row chromosome (y-axis identity) — the same colouring plot_oxford_grid() uses out of the box. Hover any dot for ortholog coordinates.
pair
Data contract: macrosynteny_orthologs.json — { pairs: [{ id, name, x: { id, name, chroms: [{ id, name, length_bp }] }, y: {…}, orthologs: [{ xc, xp, yc, yp }] }] }. xc/yc are chrom ids; xp/yp are positions in bp. Until the layer lands, the renderer falls back to a baked-in 28×27 example pair (fClaHyb_Gar × C. fuscus).
