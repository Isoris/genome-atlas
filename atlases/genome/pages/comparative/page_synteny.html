spec · phase D
Cross-species collinearity for the Gar haplotype against related Siluriformes (C. macrocephalus, I. punctatus, plus 7-9 more catfish genomes via catfish-synteny-toolkit's wfmash 1-to-1 alignments). Two views: ribbon diagram (one strip per species pair, syntenic blocks rendered as polygons) and per-chrom dotplot for a single Cgar↔Cmac pair.
Where the Inversion Atlas's page16 surfaces cross-species breakpoint coincidences with cohort candidates, this page is the genome-wide context the breakpoints live in.

phase plan
View 1 — pairwise ribbon
Two horizontal strips (e.g. Cgar above, Cmac below); polygons connect homologous blocks. Inversions = anti-parallel polygons. Translocations = chrom-jumping polygons. Toggle which species is shown below.
View 2 — multi-species ribbon stack
Cgar at the top; stacked below it, one strip per related Siluriformes genome. Side-by-side comparison of conserved vs lineage-specific rearrangements.
View 3 — per-chrom dotplot (drilled)
Reached by clicking a cell in the Oxford grid (View 4) or any chromosome in a ribbon. Full chr A × chr B dotplot for the selected pair. Dots are coloured categorically by syntenic block (one hue per block) rather than by a continuous identity ramp — adjacent blocks read as separate colour clusters, so inversions and translocations are visually distinct. Hover for block coordinates, identity, ortholog id.
View 4 — macrosyntR-style Oxford grid
Aggregated chrom-pair view: genome A on rows, genome B on columns, one dot per cell. Dot size ∝ shared-ortholog count. Colour is selectable: row chrom (categorical, one hue per row chrom A — the macrosyntR default), column chrom (categorical by chrom B), or significance (blue ≥ q_hi, yellow ≥ q_lo). Click any populated cell to zoom into the corresponding chr A × chr B dotplot in View 3.
View 1 — pairwise ribbon (mockup)
Cgar (top) × Cmac (bottom)
Top strip = genome A (Cgar), bottom strip = genome B (Cmac). Each chromosome is drawn as a coloured segment using the same 12-hue categorical palette as View 4's grid, so the colour you saw on a row in the Oxford grid is the same colour you see here on the corresponding strip segment. Polygons connect homologous blocks: a normal block is a forward trapezoid; an inversion is drawn as an anti-parallel polygon (the polygon "crosses itself"); a translocation is a chrom-jumping polygon. Hover a polygon for block coordinates + size; click to drill into View 3.
Hover a polygon for block coordinates; click drills into the chr A × chr B dotplot in View 3. The species toggle for "which non-focal to compare against" reuses the page_synteny focal selectors above the Oxford grid.
View 2 — multi-species ribbon stack (mockup)
Cgar + 3 Siluriformes
Same chrom palette, stacked phylogenetically. Cgar at the top; below it, one strip per related Siluriformes genome. Polygons connect adjacent strips only — comparisons between non-adjacent species are read transitively through the intermediate strip. A clean colour column means a chromosome is conserved across the whole stack; a colour break partway down marks a lineage-specific rearrangement.
Phylogeny order is read from the manifest's comparison_set (phase D contract). Adjacent-only polygons keep the visual budget fixed even when more genomes are added — adding a fifth strip only adds the strip and its in-between polygons.

Per-chrom dotplot for the active drilled pair. Each dot is one ortholog anchor (x = order on chrom A, y = order on chrom B). Dots are coloured categorically by syntenic block — one hue per contiguous block — so inversions read as anti-diagonal clusters and translocations as off-diagonal clusters in distinct colours. Import schema — synteny_oxford_grid.json (per focal pair)
contract
One JSON per ordered (genome A, genome B) pair. File path: data/comparative/oxford/<a_id>_<b_id>.json (e.g. cgar_cmac.json). Cells are sparse — only those with at least one ortholog need to appear; empty cells are inferred and rendered blank. 
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "synteny_oxford_grid",
  "type": "object",
  "required": ["pair_id", "genome_a", "genome_b", "cells"],
  "properties": {
    "pair_id":  { "type": "string", "description": "e.g. 'cgar_cmac'." },
    "method":   { "enum": ["macrosyntR", "manual"], "default": "macrosyntR" },
    "ortholog_source": { "type": "string", "description": "e.g. 'OrthoFinder v2.5.5'." },

    "genome_a": { "$ref": "#/$defs/genome" },
    "genome_b": { "$ref": "#/$defs/genome" },

    "cells": {
      "type": "array",
      "description": "Sparse: include only chrom-pairs with ≥1 ortholog.",
      "items": {
        "type": "object",
        "required": ["chrom_a", "chrom_b", "n_orthologs"],
        "properties": {
          "chrom_a":      { "type": "string" },
          "chrom_b":      { "type": "string" },
          "n_orthologs":  { "type": "integer", "minimum": 0 },
          "fisher_p":     { "type": "number" },
          "fisher_q":     { "type": "number", "description": "BH-adjusted." },
          "significant":  { "type": "boolean", "description": "True if q < 0.05." }
        }
      }
    },

    "thresholds": {
      "type": "object",
      "properties": {
        "q_hi": { "type": "number", "default": 0.01, "description": "Below = large blue." },
        "q_lo": { "type": "number", "default": 0.05, "description": "Below = small yellow." }
      }
    }
  },

  "$defs": {
    "genome": {
      "type": "object",
      "required": ["id", "chroms"],
      "properties": {
        "id":    { "type": "string" },
        "label": { "type": "string" },
        "chroms": {
          "type": "array",
          "items": {
            "type": "object",
            "required": ["id", "gene_count"],
            "properties": {
              "id":         { "type": "string" },
              "gene_count": { "type": "integer", "minimum": 0 },
              "length_bp":  { "type": "integer", "minimum": 1 }
            }
          }
        }
      }
    }
  }
}
Chromosome palette key
reference
One categorical hue per chromosome. Slots 1–11 step by 30° around the colour wheel; slots 12–13 are 15°-step infills for karyotypes with >11 chroms; fused is reserved for fused/transition blocks (used in View 3 above). Tokens live in atlases/genome/css/genome.css under :root; paint a <rect> or <polygon> with the matching .ga-chrom-N utility class.
